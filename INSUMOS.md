# INSUMOS

## 1. Referências da atividade

O material da aula 2 sobre desenvolvimento de aplicações orienta a utilização de pesquisa, projeto, desenvolvimento em etapas e testes. O professor disponibilizou material de exemplo para seguir, como fazer a documentação, insumos e os requisitos.

## 2. Referências visuais

Foram utilizadas como inspiração as referências citadas no material da disciplina:

- **Skoob** referência para observar a organização de abertura e recursos, link do site: https://www.skoob.com.br
- **Estante Virtual** referência para observar uma estética limpa, link do site: https://www.estantevirtual.com.br
- **Blinkist:** referência para observar o uso de rolagem e animações em uma página de apresentação, link do site: https://www.blinkist.com

As referências serviram apenas para observar organização e ideias de composição. O conteúdo, a identidade visual e os textos deste projeto foram produzidos especificamente para o site Páginas Antigas.

## 3. Paleta de cores

- Azul principal: `#183f52`
- Azul escuro: `#102f3d`
- Laranja destaque: `#e7784d`
- Creme de fundo: `#fbf8f2`
- Branco: `#ffffff`
- Texto: `#536066`

A paleta foi definida para transmitir uma aparência relacionada a livros e papel, utilizando azul para estabilidade e laranja para destaque.

## 4. Biblioteca de efeito

Foi utilizada a biblioteca **AOS (Animate On Scroll), versão 2.3.1**, carregada por CDN.

Fonte indicada no material da aula:
`https://unpkg.com/aos@2.3.1/dist/aos.css`
e
`https://unpkg.com/aos@2.3.1/dist/aos.js`

Licença e informações da biblioteca devem ser conferidas na documentação oficial da versão utilizada.

## 5. Restrições

- O site deve ser uma página única.
- Não deve depender de backend ou banco de dados.
- Deve funcionar localmente abrindo `index.html`.
- O projeto deve manter HTML, CSS e JavaScript separados.
- Não foram utilizadas imagens externas para as capas; foram usados elementos gráficos e emojis para manter o projeto simples.
