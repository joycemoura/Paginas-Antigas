# DOCUMENTAÇÃO

## 1. O que é o site

O **Páginas Antigas** é um site de divulgação de uma livraria online. A página apresenta um catálogo de livros, permite filtrar os títulos por categoria e oferece um formulário para solicitar um livro. A proposta é criar uma experiência visual simples, organizada e agradável para leitores.

## 2. Como instalar e rodar

Não é necessário instalar Node.js, banco de dados ou servidor.

1. Baixe ou clone o repositório.
2. Mantenha `index.html`, `estilo.css` e `script.js` na mesma pasta.
3. Abra `index.html` com dois cliques ou pelo navegador.
4. Para carregar AOS 2.3.1 e a fonte externa, é necessária conexão com a internet.

O projeto foi pensado para funcionar como uma página única.

## 3. Tecnologias e versões

- **HTML5:** estrutura e conteúdo semântico da página.
- **CSS3:** cores, tipografia, layout, responsividade, cards, formulário e efeitos de interação visual.
- **JavaScript:** filtro de categorias, menu mobile, preenchimento automático do formulário, validação, integração da mensagem com WhatsApp e botão voltar ao topo.
- **AOS 2.3.1:** biblioteca JavaScript utilizada para animar elementos quando eles entram na área visível da página.
- **Google Fonts:** fontes DM Sans e Playfair Display utilizadas na interface.

## 4. Revisão dos elementos que compõem o site

- **HTML:** organiza o conteúdo em cabeçalho, abertura, catálogo, etapas, depoimentos, formulário e rodapé.
- **CSS:** define a identidade visual, os cartões de livros, a paleta, os espaçamentos e a adaptação para telas menores.
- **JavaScript:** adiciona comportamento aos filtros, botões, formulário, menu e rolagem.
- **AOS:** adiciona os efeitos de entrada utilizados nas seções e cartões.

## 5. Ambiente de desenvolvimento

O projeto pode ser desenvolvido e executado em:
- Sistema operacional: Windows.
- Editor: Visual Studio Code.
- Navegador: Google Chrome, Microsoft Edge ou equivalente.
- Execução: abertura direta do `index.html`.
- Internet: necessária para carregar AOS 2.3.1 e as fontes externas.
