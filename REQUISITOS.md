# REQUISITOS

## Requisitos funcionais

1. **RF01 — Navegação:** o site deve apresentar uma navegação em uma única página, com links que levam às seções do próprio site.
2. **RF02 — Catálogo:** o site deve apresentar livros com título, autor, categoria e preço.
3. **RF03 — Filtro:** o usuário deve conseguir filtrar os livros pelas categorias disponíveis.
4. **RF04 — Solicitação de livro:** o botão “Solicitar” de cada livro deve levar o usuário ao formulário e preencher automaticamente o livro escolhido.
5. **RF05 — Formulário:** o formulário deve solicitar nome, e-mail, telefone, livro de interesse e mensagem opcional.
6. **RF06 — Validação:** nome, e-mail e livro devem ser campos obrigatórios.
7. **RF07 — WhatsApp:** ao enviar o formulário corretamente, o JavaScript deve montar uma mensagem e abrir o WhatsApp com os dados da solicitação.
8. **RF08 — Menu mobile:** em telas estreitas, o menu deve ser substituído por um botão que abre e fecha a navegação.
9. **RF09 — Voltar ao topo:** após rolar a página, deve aparecer um botão para retornar ao início.
10. **RF10 — Efeitos visuais:** elementos das seções devem utilizar uma biblioteca JavaScript de animação.

## Requisitos não funcionais

1. **RNF01 — Tecnologia:** utilizar HTML, CSS e JavaScript.
2. **RNF02 — Página única:** o projeto deve funcionar em uma única página HTML, sem navegação para outros endereços.
3. **RNF03 — Responsividade:** o layout deve se adaptar a computadores, tablets e celulares.
4. **RNF04 — Execução:** o projeto deve abrir localmente a partir do arquivo `index.html`.
5. **RNF05 — Biblioteca:** utilizar AOS na versão 2.3.1 para os efeitos de entrada dos elementos.
6. **RNF06 — Usabilidade:** os textos devem apresentar contraste adequado e os campos do formulário devem possuir identificação por meio de labels.
7. **RNF07 — Organização:** HTML, CSS e JavaScript devem permanecer separados em seus respectivos arquivos.
8. **RNF08 — Sem servidor:** não é necessário banco de dados ou backend para executar a atividade.
9. **RNF09 — Dependência externa:** AOS e a fonte utilizada pelo CSS são carregadas pela internet e, portanto, o efeito visual e a tipografia podem depender de conexão.
